# ParallelExpectationMaximizationClustering

High Performance Computing (HPC) project (University of Trento): parallel Expectation-Maximization (EM) clustering.

**Authors:** 
- Michael Bernasconi
- Gabriele Fronzoni

## Repository structure

```
.
├── src/             # Source files (.c / .cpp)
├── include/         # Header files
├── data/            # Input datasets
├── results/
│   ├── logs/        # Raw execution logs
│   ├── tables/      # Benchmark tables
│   ├── plots/       # Generated plots
│   └── plots.py     # Script producing the plots from the results
├── doc/
│   ├── latex/       # IEEE-style report (Group6-Report.tex)
│   ├── project-guide.md  # Project requirements, report outline, EM background, experiment plan
│   ├── question.md       # Open questions for the instructors
│   └── todo.md           # Task list
├── makefile         # Build rules
└── README.md
```
