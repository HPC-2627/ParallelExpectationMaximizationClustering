# Papers and references

Our implementations and the reference / source of each technique: online link to the paper, how it is connected to our code, and the verification status (`✅` verified against code and paper, `⚠️` reference valid or weak source, specific numbers/sections/paywall to double-check). The `#` is the id used to cite a row from the code comments (e.g. `doc/papers_and_references.md #4.2` in the headers of the opt1/opt2 full sources) and from `doc/todo.md`; it matches the prefix of the local PDF in `doc/papers/` (local copies only, not versioned).

Note on variants in the codebase: sequential implementations exist only for the two baselines (`PEMC-baseline-sequential-diagonal.c` and `PEMC-baseline-sequential-full.c`); `opt1` and `opt2` are all hybrid `MPI + OpenMP` implementations (`diagonal` and `full`). Both `opt2` start from the baseline of their model: **opt2 diagonal** = baseline diagonal + communication optimization; **opt2 full** = baseline full (two passes, stored responsibilities) + communication optimization. Each is compared with its baseline.

Strength of the link:
- **direct** = same algorithm/parallelization pattern as in the paper;
- **partial** = same underlying idea, adapted to a different parallel model, data layout, or implementation;
- **own** = no external paper, derived from course principles (Amdahl, fork/join, false sharing) or our own measurements;
- **none** = related work cited for contrast: a different approach that we do not implement.
